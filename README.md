# 한국의 지구 온난화 시각화 프로젝트

## 개요
이 프로젝트는 **D3.js**를 활용하여 한국의 지구 온난화 문제를 분석하는 인터랙티브 웹 시각화입니다.  
다양한 기후 데이터를 기반으로 시각적 요소를 통해 기온 변화, 폭염, 생태계 변화, 해수면 상승, 강수량 변화를 효과적으로 표현하였습니다.

## 프로젝트 정보
- **프로젝트 명**: 지구 온난화 시각화
- **팀원**: 한상, 가희, 민기, 윤서, 태린
- **소속**: 서울대학교 빅데이터 핀테크 AI 고급 전문과정
- **진행 기간**: 2024년 7월 30일 - 8월 29일
- **배포 URL**: [Global Warming Visualization](https://hsrhee97.github.io/global_warming_kor_vis/)

## 주요 기능
### 🌡️ 기온 상승 분석
- **과거 평균 대비 상대 기온 변화 (1908 - 2023)**
  - 기상청 데이터를 활용하여 1960년 이전과 이후의 기온 변화를 비교
  - 색상 변화와 라인 차트를 활용하여 기온 상승 패턴을 시각화

- **여름 일별 최고 기온 변화 (1973 - 2023)**
  - 전국 9개 지역의 6~8월 최고 기온 데이터를 기반으로 히스토그램 애니메이션 구현
  - 최근 기온 분포가 오른쪽으로 이동하는 현상 분석

- **월별 평균 기온 변화 (1965 - 2024)**
  - 연도별 월평균 기온 데이터를 시각화하여 최근 이상 고온 현상을 분석

- **한국 기온 상승 바코드 시각화 (1908 - 2023)**
  - 연도별 평균 기온 편차 데이터를 활용하여 바코드형 컬러맵 구현

### ☀️ 폭염과 열사병 영향 분석
- **폭염 발생 빈도 변화 (1973 - 2024)**
  - 연간 33℃ 이상 기록된 날 수 증가 추세를 바 차트로 시각화

- **기상 재해로 인한 사망자 수 증가 (2011 - 2019)**
  - 태풍, 홍수, 폭염 등 기후 재해로 인한 사망자 수와 폭염일수의 관계 분석

- **열스트레스 지수 변화 (1974 - 2050 예측 포함)**
  - WBGT (습구흑구온도) 지수를 활용하여 열스트레스 수준을 분석하고 미래 예측 데이터 포함

### 🦋 생태계 변화 분석
- **기온 상승에 따른 곤충 개체 수 변화**
  - 2022~2023년 서울시 러브버그 민원 신고 데이터를 지도 기반 버블 차트로 시각화

- **해양 생태계 변화 및 온난화 영향 분석**
  - 해양 표층 온도 상승과 해양 생물 분포 변화 데이터 분석 및 시각화

### 🌊 해수면 상승 및 강수량 변화
- **강수량 네트워크 분석 (1997 - 현재)**
  - 전국 방재 기상 관측소 데이터를 활용하여 국지성 호우 증가 여부를 네트워크 그래프로 표현

- **국내 해수면 상승 데이터 시각화 (1989 - 2020)**
  - 해수면 높이 변화 데이터를 기반으로 장기적인 상승 추세 분석

- **미래 시나리오별 해수면 침수 면적 예측 (2050년, 2100년)**
  - RCP 4.5, RCP 8.5 시나리오를 비교하여 여의도 면적 대비 침수 지역 크기 시각화

## 사용 기술
- **프론트엔드**: HTML, CSS, JavaScript
- **시각화 라이브러리**: D3.js
- **데이터 처리**: Python (Pandas, NumPy)
- **배포**: GitHub Pages
- **데이터 소스**:  
  - 기상청 API를 활용하여 기온 및 강수량 데이터 다운로드 및 전처리
  - 국립해양조사원의 해수면 상승 데이터 활용
  - 서울시 민원 데이터를 분석하여 생태계 변화 반영
